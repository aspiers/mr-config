Replacing a customised myrepos + Stow setup: FOSS comparison

Tools that keep a registry of many repositories and run batch and automated per-repo workflows, judged against an audit of ~/.config/mr (about 440 repos), the mr fork in ~/.GIT/3rd-party/mr, and the requirement that GNU Stow stays.

Evidence observed 2026-10-16 (UTC); activity window 2025-10-16 to 2026-10-16. Recommendation order follows the stated use case.

Recommendedmyrepos upstream (rebase your fork onto it)

Stay on mr. Rebase your 62 fork commits onto upstream myrepos, offer the generic ones (describe action, stow transparency, MR_AVOID_RECACHE) upstream, and switch to upstream lib/stow where it covers you. That removes the real cruft, a fork 527 commits behind, and an AI agent can do it reliably because the existing config is the test suite.

Shared extensionsYour mr fork + mr-config (today)

For economies of scale, split the generic parts of lib.d/ and sh.d/ (remotes, autosync, skippers, confidential repos) into a documented library others can include, like landonb/ohmyrepos does. sawander28/mr-config already copies your layout by hand.

If leaving mrmani

mani is the only maintained standalone alternative with a real registry, tags, tasks and parallelism, but hooks, host skips and Stow would become your own wrappers again, so the custom code moves rather than shrinks.

Not NixNix + home-manager

home-manager can generate .mrconfig, but it has no daily multi-repo commands, its installer needs sudo for /nix, and in practice people use it to drop Stow.

Conditions and evidence
  • Shortlist. Discovered, not user-named. Included: tools that manage a list of repositories with batch operations, plus provisioning and dotfile tools often suggested as replacements. Excluded from rows: Oh My Repos (an mr add-on, worth borrowing its infuse action), mg (mr reimplementation that drops plugins), gitopolis (too thin), Tuckr (replaces Stow), dotter/rotz/comtrya (dotfile managers), gws/clowder/gg (inactive since 2020-23). Not exhaustive. Oh My Repos sawander28/mr-config

R1-R10 come from the audit: grouped registry with private overlay; daily batch ops with parallel jobs; fixups, hooks and custom verbs; shared shell helpers and per-repo variables; host, missing-executable and lazy skipping; automatic multi-remote setup; GNU Stow; svn/cvs/tarballs; fresh-machine bootstrap; systemd units for git-annex autosync. Partial means it needs wrapper code.
  • Evidence limits. Stars measure attention, not quality, and low churn can mean maturity (myrepos).
